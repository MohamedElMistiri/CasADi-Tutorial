# Exercises and solutions

Exercises are grouped into six cumulative notebooks:

1. Symbolic matrices and sparse derivatives
2. Functions and automatic differentiation
3. Integration and sensitivities
4. NLP formulation and diagnostics
5. CSTR estimation and control
6. UR5e trajectory optimization

Start in `exercises/`. Compare your work with the corresponding notebook in
`solutions/` only after attempting each task. Solution notebooks are executed in
CI and include numerical assertions, making expected behavior explicit.
