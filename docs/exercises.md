Attempt each task before comparing with its solution. Solutions implement every
requested task and are executed in CI with numerical assertions. Exercise
scaffolds intentionally leave work to the reader; documentation renders them
without executing unfinished tasks. Explain the result and its assumptions before
using the numerical checkpoints.
